# 💰 Friend Expense Tracker

A simple and responsive expense tracker created as part of an **MLH Challenge**.

The goal of this project was to **build something useful for a friend**. I created this application to help a friend keep track of their daily spending in a simple and organized way.

## 🎯 Why I Built This

My friend wanted a simple way to keep track of everyday expenses without using a complicated finance application.

So I created a lightweight expense tracker where they can quickly record what they spend and see how much they have spent.

## ✨ Features

* ➕ Add new expenses
* 💵 Enter the expense amount in Sri Lankan Rupees (Rs.)
* 🏷️ Select an expense category
* 📊 View total spending
* 🔢 View the number of expenses
* 🗑️ Delete expenses
* 📱 Responsive design for mobile and desktop

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🚀 How to Run

1. Clone this repository.

2. Open the project folder in VS Code.

3. Open `index.html` using a browser.

4. For easier development, use the **Live Server** extension in VS Code.
